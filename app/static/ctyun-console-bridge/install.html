安装天翼云控制台桥接扩展

这个扩展用于把平台后台保存的天翼云登录态写入本机 Chrome，然后打开官方控制台。

下载扩展 zip

安装步骤

  1. 下载 zip 后解压到一个固定文件夹。
  2. 打开 Chrome 地址栏：chrome://extensions/。
  3. 右上角打开“开发者模式”。
  4. 点击“加载已解压的扩展程序”，选择刚才解压出来的文件夹。
  5. 回到平台，点击账号后的“官方控制台”。

注意事项

打开某个账号时，扩展会清理本机 Chrome 中已有的天翼云 cookie，再写入当前账号的登录态。也就是说本机 Chrome 同一时间只保持一个天翼云账号。

扩展只处理 ctyun.cn 域名，不会读取或上传其他网站的数据。
